OPTION 1: INSTANT START (No Installation Required)
================================================================================

Just double-click this file:
  → vehicle-booking-register-4.html

That's it! The booking system will open in your browser.
Data is saved in your browser (LocalStorage).

================================================================================
OPTION 2: FULL VERSION WITH DATABASE (Requires Node.js)
================================================================================

Step 1: Check if Node.js is installed
  - Open Command Prompt (cmd)
  - Type: node --version
  - If you see a version number, you're good!
  - If not, download from: https://nodejs.org/

Step 2: Start the server
  - Double-click: start-server.bat
  - Wait for "Server running on http://localhost:3000"
  
Step 3: Open in browser
  - Go to: http://localhost:3000

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Option 1 doesn't open
Solution: Right-click → Open With → Choose your web browser

Problem: Option 2 says "Node.js not found"
Solution: Install Node.js from https://nodejs.org/

Problem: Port 3000 is already in use
Solution: Close other programs using port 3000, or edit server.js

Problem: Bookings don't save
Solution: Check browser console (F12) for errors
